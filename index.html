VaultGlass · User Guide

Your personal credential dashboard. Save login details, organise them by category, generate passwords and quickly find what you need. Follow these steps to get started.

🔐 1. Open & unlock

Follow the vault-door prompt, then sign in or set up your master password as instructed on screen. Keep your master password and recovery information in a safe place.

➕ 2. Add a credential

Select New or Add Credential. Enter a name, website, username/email and password. Optionally add a phone number, notes, category or OTP secret. Select Save.

🗂️ 3. Create categories

Select ＋ Manage beside Categories to add or customise groups with a name, icon and colour. Assign them in a credential's Category field. Select a category chip to filter entries; select it again to show all.

✨ 4. Choose a view

Grid arranges cards in a responsive gallery. Deck shows large swipeable cards: scroll sideways to explore. List makes compact rows for fast scanning. Each view has its own transition animation.

🔎 5. Search & filter

Use the search bar or press / when outside a text field. Filter by Favorites, OTP, Weak or Reused, and sort by recent update or name. Clear filters resets the selection.

📋 6. View, copy & edit

Select a credential card to see its details and edit it. Use User or Password to copy those values; star an entry to mark it as a favorite. One-time codes appear when an OTP key has been added.

🛡️ 7. Security tools

Open the navigation menu to find Security Audit for password strength, reuse and 2FA checks. The Password Generator creates random passwords. Use the dashboard health indicators to review your vault.

📦 8. Import, export & backup

Use Import / Export to transfer credentials. Prefer the passphrase-protected encrypted JSON backup. CSV and plain JSON exports contain readable secrets—protect or delete them securely when finished.

🎨 9. Personalise & lock

Choose a theme from the appearance controls. Use Lock now when stepping away. Review your recovery credentials before changing your master password.

📱 10. Mobile & accessibility

On smaller screens, scroll category chips sideways and swipe through Deck cards. If your device requests reduced motion, animated transitions are automatically limited.

Important: This app stores highly sensitive information. Use a unique, strong master password, keep a protected backup, and avoid using it on shared or untrusted devices. Before publishing online, independently review its security design, storage, authentication, and deployment configuration. Visual polish does not establish security.
